Comment supprimer votre compte CuandoMeToca

Dernière mise à jour : octobre 2026
Español English Deutsch 简体中文 Català Euskara Italiano Français
CuandoMeToca est une app de rappel de médicaments développée par Jonatan Ortega González (devlicius). Le compte est facultatif. Si vous en avez un, vous pouvez le supprimer vous-même à tout moment depuis l'app, sans nous écrire.

Supprimer votre compte depuis l'app (recommandé)

  1. Ouvrez l'app et touchez le menu ⋮ dans le coin supérieur.
  2. Allez dans Compte.
  3. Touchez Supprimer le compte.
  4. Confirmez votre identité (avec Google, avec Apple ou en saisissant votre mot de passe) et acceptez.

La suppression est immédiate.

Vous n'avez plus accès à l'app ?

Écrivez depuis l'e-mail de votre compte à devlicius.online@gmail.com avec l'objet « Supprimer le compte CuandoMeToca ». Nous vérifierons la demande et supprimerons le compte sous 30 jours au maximum.

Ce qui est supprimé

Suppression immédiate et définitive
  • Votre compte de connexion (e-mail, nom et méthode de connexion). Si vous utilisiez Apple, l'accès de l'app à votre identifiant Apple est aussi révoqué.
  • Toute votre copie dans le cloud : médicaments, prises, rendez-vous et poids.
  • Vos liens d'aidant, dans les deux sens, et les codes d'invitation en attente. La personne qui vous accompagnait ne voit plus vos médicaments.
  • Les identifiants de notification de vos appareils et votre fuseau horaire.
  • Le statut de votre abonnement dans notre base de données et votre fiche client chez RevenueCat.

Ce qui n'est pas touché

Les données de votre téléphone sont conservées pour que vous puissiez continuer à utiliser l'app sans compte. Pour les supprimer aussi, utilisez ⋮ → Supprimer toutes les données ou désinstallez l'app.

Votre abonnement n'est pas résilié : la facturation est gérée par Apple ou Google. Résiliez-le depuis les réglages d'abonnement de votre store.

Apple, Google et RevenueCat peuvent conserver leurs propres traces des achats selon leurs politiques et leurs obligations légales.

Supprimer les données sans supprimer le compte

⋮ → Supprimer toutes les données efface les données du téléphone et, si vous êtes connecté, la copie dans le cloud aussi, mais garde votre compte. Par ailleurs, la copie dans le cloud se supprime d'elle-même 12 mois après la fin de votre dernière offre.
